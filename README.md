# Data and analysis for *Emergence of hierarchical structure through repeated dyadic interaction across developmental compositions*

This repository contains the data and analysis materials for the manuscript **“Emergence of hierarchical structure through repeated dyadic interaction across developmental compositions.”**

The repository is organized by study:

- [Study 1](Study1/) — repeated reciprocal learning in adult–adult dyads
- [Study 2](Study2/) — comparison of adult–adult, child–child, and adult–child dyads

Each study directory contains:

- raw data used for reconstruction,
- processed analysis datasets,
- Python preprocessing code, and
- R Markdown code for reproducing the statistical analyses and manuscript figures.

Detailed information about the study design, raw-data structure, preprocessing steps, validation checks, and analysis workflow is provided in the README within each study directory.

## Reproducibility workflow

For each study, the processed datasets can be reconstructed from the raw data using the corresponding Python preprocessing script. The statistical analyses and figures can then be reproduced by knitting the corresponding R Markdown file.

See:

- [Study 1 README](Study1/README.md)
- [Study 2 README](Study2/README.md)
